# AIGC Visual Portfolio

AI 漫剧制作 / AIGC 视觉设计个人作品集第一版。

## Start

```bash
npm install
npm run dev
```

Build verification:

```bash
npm run build
npm run lint
```

## Replace assets

- Avatar: `public/assets/profile/`
- Character work: `public/assets/projects/character/`
- Environment work: `public/assets/projects/environment/`
- Prop work: `public/assets/projects/props/`
- Videos and poster frames: `public/assets/projects/video/`
- PDF resume: `public/assets/resume/resume.pdf`
